Integracion App Cocina + instalador NSIS

- Hub: servidor HTTP local en 127.0.0.1:7331/import para recibir
  layouts desde App Cocina (POST JSON CocinaLayoutImport).
  Escribe en %APPDATA%/.../cocina-inbox/*.json para el flujo
  existente de cocinaBridge (importFromCocina).
- Hub: electron-builder configurado (NSIS, signAndEditExecutable=false
  para evitar winCodeSign sin admin). Script build:installer.
- App Cocina (DistribuirCocinaMonitoresPage): boton "Enviar al Monitor
   Hub" que construye slots desde la asignacion actual (urls
  modo=completo-fijo&perfil=auto) y POSTea al Hub local.

Instalador generado: GambusinasMonitorHub-Setup-0.1.0.exe (82.8 MB),
se publica como asset de GitHub Release para descarga.
