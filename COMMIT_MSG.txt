Fases 2-6: Electron + React UI, modos, perfiles, bridge Cocina, pulido

Fase 2 - Electron + UI minima:
- electron-vite (main/preload/renderer) con TypeScript.
- Main process: BrowserWindow anclada al monitor primario, IPC centralizado.
- Preload: contextBridge expone window.hub (API tipada).
- Renderer React: App + MonitorCard + WindowPicker.

Fase 3 - Modos de ventana:
- Botones fullscreen / maximizado / restaurar por ventana.
- moveWindowToMonitor con modo (normal/maximized/fullscreen).
- Fullscreen real borderless por monitor via SetWindowPos + SetWindowLongPtrW.

Fase 4 - Perfiles de layout:
- layoutStore: persistencia JSON en %APPDATA%/.../layouts.
- UI LayoutPanel: guardar layout actual, listar, aplicar, borrar.
- applyLayout: reutiliza ventanas abiertas (match por process/titleContains)
  o abre Chrome/Edge con url posicionada en el monitor destino.

Fase 5 - Bridge con App Cocina:
- cocinaBridge: inbox (%APPDATA%/.../cocina-inbox/*.json) + dialogo de archivo.
- UI: importar desde inbox o archivo JSON (formato CocinaLayoutImport).

Fase 6 - Pulido:
- Polling cada 3s de monitores y ventanas (hot-plug / cambios).
- Manejo de errores comprensible en UI (banner de error).
- Identificar monitores (overlay numerado por display, 2s).
- Logger con timestamp y nivel.

Notas tecnicas:
- koffi marcado como external en el build del main (carga el .node
  correcto para el ABI de electron en runtime).
- Callbacks sincronos (EnumWindows/EnumDisplayMonitors) pasados como
  funcion JS directa (no koffi.register).
- Structs Win32 via koffi.alloc + encode + decode.
- Buffers (no Uint16Array) para params uint16*/uint32*.

Validado: typecheck OK, build OK, smoke test electron arranca sin
errores y crea la ventana del Hub.
